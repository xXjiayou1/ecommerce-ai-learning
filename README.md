### 遇到的问题与解决方法
1. **问题**：PowerShell中`%USERPROFILE%`环境变量不生效
   **解决**：PowerShell使用`$env:USERPROFILE`语法
2. **问题**：Git提示"not a git repository"
   **解决**：在本地文件夹执行`git init`命令初始化仓库
3. **问题**：推送时提示"src refspec main does not match any"
   **解决**：先创建并提交一个文件，再拉取远程内容合并
